# Solatro-App 🎴🎵
Um aplicativo web interativo - mobile - não oficial feito de fã para fãs de Solatro e Balatro. Combinando a ambientação sonora de Balatro com uma ferramenta prática para acompanhar e identificar os chefes do jogo.

## 💡 Sobre o Projeto

Este projeto nasceu de uma necessidade pessoal e do desejo de aprimorar minha própria experiência de jogo. Como fã e Designer Gráfico, decidi aplicar minha expertise no desenvolvimento de uma interface funcional, direta e temática em um único arquivo web.

O app NÃO possui fins lucrativos e foi criado de fã para fãs, com o objetivo único de quebrar o tédio em que eu me encontrava.
